# capacitor.config.json

[Exact copy](../original/capacitor.config.json)

Line numbers refer to the original file, before teaching comments.

### Line 1

```text
{
```

Opens the Capacitor configuration object.

### Line 2

```text
  "appId": "com.gickistudios.moshertime",
```

Uses com.gickistudios.moshertime as the stable native application identifier for generated Android/iOS projects.

### Line 3

```text
  "appName": "Mosher Lawns HR",
```

Displays “Mosher Lawns HR” as the native app name, even though the repository/package is named Timekeeper.

### Line 4

```text
  "webDir": "www"
```

Tells Capacitor that the compiled web assets to copy into native projects are in the www directory.

### Line 5

```text
}
```

Closes the Capacitor configuration object.
