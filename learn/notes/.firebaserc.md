# .firebaserc

[Exact copy](../original/.firebaserc)

Line numbers refer to the original file, before teaching comments.

### Line 1

```text
{
```

Opens the JSON object that stores Firebase CLI project aliases.

### Line 2

```text
  "projects": {
```

Names the object of aliases used by Firebase CLI commands.

### Line 3

```text
    "default": "demo-timekeeper"
```

Maps the alias “default” to the local/emulator project ID demo-timekeeper; commands without --project use this ID.

### Line 4

```text
  }
```

Closes the projects alias object.

### Line 5

```text
}
```

Closes the file’s root JSON object.
